# Rules Skill

Defines which skill to use based on the type and purpose of the text.

- Use `caveman`, `i have adhd`, and `humanizer` for text that is not UI text or a reply.
- Use `humanizer` for UI text that is not instructional.
- Use `asd-ste100` for instructional text.
