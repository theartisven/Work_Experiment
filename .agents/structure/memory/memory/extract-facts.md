# Extract facts

## When to select

Select this rule when a span contains a standalone claim, number, date, preference, decision, or event.

## Instructions

1. Keep only facts that are specific, self-contained, and likely to matter later.
2. Rewrite each fact as one plain sentence that makes sense without surrounding context.
3. Replace pronouns with the person's name when needed.
4. Skip small talk, hedging, and information the user is likely to repeat.

## Output

One sentence per fact.
