# Identify goals

## When to select

Select this rule when a span states or implies an objective, such as "I want to", "the plan is", "we need to", a deadline, or a success criterion.

## Instructions

1. State the goal in the person's terms.
2. Include any stated deadline or success criterion.
3. Mark the goal as new, ongoing, or dropped.

## Output

`- Goal (status): <goal statement>, <deadline or criterion if any>`
