# Track entities

## When to select

Select this rule when a person, place, organization, pet, or object is named or referred to again.

## Instructions

1. List each entity once, using its full name.
2. Record its type and the details in the span, such as its role, relationship, location, or status.
3. If `memory-bank.md` already lists the entity, add the new detail there instead of creating a duplicate.

## Output

`- Entity (type): new detail`
