# Refine memory rules

Use this process after a task when recall was poor.

## 1. Record failures

Add each failure to `evolution/hard-cases.md`. Include the span, what should have been stored, what was stored, and the rule that should have caught it.

## 2. Group recent cases

Review the last five to ten cases. Group them by the rule that failed, or by an uncovered gap.

## 3. Choose changes

Make no more than two changes per review cycle. For each group, choose one action:

- **Edit a rule:** Tighten its selection criteria or instructions so it catches the case.
- **Add a rule:** Create `memory/<new-name>.md` and add it to the table in `SKILL.md` only when no existing rule fits and at least three cases show the same gap.
- **Do nothing:** Leave one-off failures unchanged.

## 4. Log changes

Add each change to the bottom of this file with its date and reason.
